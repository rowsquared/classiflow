# Security policy

Report a suspected vulnerability through GitHub’s private reporting form.
Include the affected version or commit, steps to reproduce, and the impact.
Use synthetic examples and redact any credentials or personal data.
[Report a vulnerability privately](https://github.com/rowsquared/classiflow/security/advisories/new)

Security fixes target the current release. See the
[application access model](docs/security.md) for permission and isolation details.
